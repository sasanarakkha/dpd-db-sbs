# Plan — Translate skill overhaul (Russian)

**Issue:** local #53 — https://github.com/sasanarakkha/dpd-db-sbs/issues/53 · Rehearsal run: #56 (not this thread)
**Spec:** `kamma/threads/20261116_translate-skill-overhaul/spec.md` — read it first.

## Architecture Decisions
- **One model chain: `default_models` in `tools/ai_models.json`.** The runner stops pinning; workhorses pass `provider=None, model=None` so `AIManager` walks the chain. `synonym_audit.py` walks the same pairs itself (explicit pair per call) so it knows which model answered (`judge_model`). `tools/ai_manager.py` and `grounded_models` are not touched.
- **Off-peak logic in `kamma/translate/scripts/offpeak.py`** — skill-local (`kamma/` is already in `unique_paths`, no registry entry needed); only `batch_runner.py`, `synonym_audit.py`, `model_benchmark.py` import it.
- **Apply contract = reviewed TSV.** No AI, no cache at apply. Apply commits per row and appends the undo record immediately — deliberately not batched.
- **Reject memory in tracked `kamma/translate/rejects.json`** — must survive sessions, so not `temp/`.
- **Benchmark last.** One combined test answers both open model questions (judge Flash vs pro; OpenRouter fallback). The picks change only config data (plus one conditional task), so every code phase before it runs unattended; 7.4 is the only user decision.
- **Not abstracted:** no shared model-chain helper in `tools/`; only `synonym_audit.py` needs to know which pair answered.

## Global rules (every task)
- Tests zero-network (fake `AIManager`); DB paths use in-memory SQLite (pattern: `tests/test_tamil_translation.py`, `Base.metadata.create_all`). Run only by explicit file path — never bare `uv run pytest`.
- Every touched `.py`: `uv run ruff check --fix <f>`, `uv run ruff format <f>`, `uv run pyright <f>` (tests: `uv run pyright --project /dev/null <f>`), `uv run --with pyrefly pyrefly check --min-severity warn <f>`. Fix pre-existing errors in touched files with real fixes (no `# noqa`).
- No writes to `dpd.db`. Real AI calls only in Phase 7, off-peak.
- Never edit `tools/ai_manager.py`, `grounded_models`, Tamil logic. No commits; draft messages reference #53.
- Scratch under `temp/translate_overhaul/`, deleted at the end. Fish shell for any command given to the user (no heredocs).
