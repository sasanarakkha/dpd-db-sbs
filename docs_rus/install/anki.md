# DPD для Anki

Колода словарных карточек DPD доступна для [Anki](https://apps.ankiweb.net){target="_blank"}, популярного приложения для карточек. Работает на десктопе, AnkiDroid и AnkiMobile.

## Установка

(1) Скачайте последнюю версию **dpd-anki.apkg** со **[страницы релизов на GitHub](https://github.com/digitalpalidictionary/dpd-db/releases/latest){target="_blank"}**.

(2) Дважды щёлкните **dpd-anki.apkg**. Anki откроется и импортирует колоду.

Готово. Колода появится в вашем списке колод, готова к изучению.

## Обновление

Когда выйдет новая версия, снова скачайте и откройте последний **dpd-anki.apkg**. Anki распознает существующую колоду и спросит, хотите ли вы обновить её. Выберите обновление.

## Тема

Вы можете изменить цвета и шрифты карточек, отредактировав стилизацию карточек (CSS). Тема управляется цветовыми переменными `:root` в начале стилизации.

Вот настройки, которые используются для создания темы DPD по умолчанию:

```css
:root {
  --label: hsl(205, 79%, 48%);
  --hl:    hsl(198, 100%, 50%);
  --soft:  hsl(198, 100%, 95%);
  --bg:    hsl(198, 100%, 5%);
}
```

Измените значения `hsl(...)`, чтобы задать собственные цвета, затем сохраните.

### Anki Desktop

(1) Нажмите **Обзор**, чтобы открыть обозреватель карточек.

(2) Выберите любую карточку DPD.

(3) Нажмите **Карточки…**.

(4) Откройте вкладку **Стилизация** и отредактируйте CSS.

(5) Закройте окно, чтобы сохранить.

### AnkiDroid

(1) Откройте **Обозреватель карточек** и нажмите на карточку DPD.

(2) Нажмите меню **⋮** и выберите **Изменить заметку**.

(3) Нажмите меню **⋮** снова и выберите **Карточки…**.

(4) Откройте раздел **Стилизация** и отредактируйте CSS.

(5) Нажмите **стрелку назад**, чтобы сохранить.
