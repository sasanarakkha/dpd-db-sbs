# DPD для Apple Dictionary

DPD теперь доступен как родной словарь Apple (Apple Dictionary), что позволяет искать палийские слова непосредственно во встроенном приложении «Словарь» и с помощью общесистемного поиска.

⚡ Обратите внимание: это доступно только на macOS. Это не работает на iOS, iPadOS или других операционных системах.

## Коротко о главном

1. Скачайте **dpd-apple-ru.dictionary.zip** со страницы [релизов на GitHub](https://github.com/sasanarakkha/dpd-db-sbs/releases/latest){target="_blank"}
2. Распакуйте файл.
3. Переместите `Digital-Pali-Dictionary-RU.dictionary` в `~/Library/Dictionaries/`
4. Перезапустите приложение «Словарь».
5. Включите DPD в настройках словаря.

## Подробная инструкция

### Загрузка

(1) Перейдите на [страницу последнего релиза на GitHub](https://github.com/sasanarakkha/dpd-db-sbs/releases/latest){target="_blank"}.

(2) В разделе **Assets** скачайте **dpd-apple-ru.dictionary.zip**.

### Распаковка

(3) Найдите скачанный `.zip` файл в папке «Загрузки» и дважды щелкните по нему, чтобы распаковать. Вы получите папку с названием `Digital-Pali-Dictionary-RU.dictionary`.

### Установка словаря

(4) Откройте Finder и нажмите `Shift + Command + G` (или перейдите в меню **Переход > Перейти к папке...**).

(5) Введите `~/Library/Dictionaries/` и нажмите Enter.

⚡ Обратите внимание: если папки Dictionaries не существует, создайте её.

(6) Переместите папку `Digital-Pali-Dictionary-RU.dictionary` в эту папку.

### Перезапуск приложения «Словарь»

(7) Если приложение «Словарь» открыто, закройте его полностью (`Command + Q`) и откройте снова. Если оно не открыто, просто откройте его.

### Включение DPD

(8) Откройте приложение «Словарь» и перейдите в **Словарь > Настройки** (или нажмите `Command + ,`).

(9) Убедитесь, что в списке словарей отмечен **Digital Pali Dictionary RU**. Вы можете перетащить его, чтобы изменить приоритет в списке.

## Использование DPD

### Приложение «Словарь»

Введите любое палийское слово в строку поиска приложения «Словарь». DPD поддерживает флективные формы, поэтому поиск по слову **dhammassa** покажет основную словарную статью **dhamma**.

### Общесистемный поиск

Выделите любое палийское слово в любом приложении и нажмите `Control + Command + D` для быстрого появления всплывающего окна с определением. Это работает в Safari, Preview, Pages и большинстве приложений macOS.

## Обновление

Чтобы обновиться до последней версии, скачайте новейший **dpd-apple-ru.dictionary.zip** с [релизов на GitHub](https://github.com/sasanarakkha/dpd-db-sbs/releases/latest){target="_blank"}, распакуйте его и замените существующий `Digital-Pali-Dictionary-RU.dictionary` в папке `~/Library/Dictionaries/`. Перезапустите приложение «Словарь», чтобы загрузить новую версию.

Вот и всё, вы всё настроили! Наслаждайтесь поиском слов пали на macOS.
