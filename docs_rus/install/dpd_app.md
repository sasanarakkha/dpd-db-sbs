# DPD Приложение — Бета-тестирование

Приложение DPD теперь доступно для бета-тестирования.

Если вы обнаружите ошибки, проблемы с установкой, неточности в словаре или что-то непонятное, пожалуйста, отправьте отзыв.

## Скачать последнюю версию

- Страница версий: <https://github.com/digitalpalidictionary/dpd-flutter-app/releases>
- Последняя версия: <https://github.com/digitalpalidictionary/dpd-flutter-app/releases/latest>

На странице последней версии скачайте файл `.apk`, указанный в разделе **Assets**.

Полный исходный код этого приложения общедоступен и может быть проверен любым желающим здесь: <https://github.com/digitalpalidictionary/dpd-flutter-app>

В целях безопасности скачивайте и устанавливайте APK только с официальной страницы релизов на GitHub, указанной выше.

## Установка на Android

Поскольку это приложение не устанавливается из Google Play Store, Android может предупредить, что установка из этого источника заблокирована.

Для установки:

1. Скачайте последний файл `.apk` со страницы релизов.
2. Откройте скачанный `.apk` на вашем устройстве Android.
3. Если Android блокирует установку, при появлении запроса разрешите установку из этого источника.
4. Настройка обычно называется `Установка из неизвестных источников` или `Разрешить из этого источника`.
5. После разрешения вернитесь к APK и продолжите установку.

При первом запуске приложение автоматически загружает базу данных словаря. Это может занять несколько минут в зависимости от скорости вашего подключения.

## Как искать слова из других приложений

Вы можете использовать DPD практически из любого приложения или веб-сайта на Android двумя способами:

1. Нажмите и удерживайте любое слово или выделите текст, затем нажмите `Поделиться` и выберите `DPD`.
2. Или выберите слово и нажмите значок приложения `DPD` напрямую, если Android отображает его в меню выделения текста.

Оба метода открывают выбранный текст в DPD и имеют одинаковый эффект.

Совет:

- Чем чаще вы делитесь через DPD, тем больше вероятность, что Android переместит его на первую страницу меню «Поделиться».
- После нескольких использований DPD может стать одним из ваших наиболее частых объектов для «поделиться».

## Как искать слова внутри приложения

- Дважды щёлкните любое слово в приложении для его поиска.
- Введите слово непосредственно в строку поиска, используя Unicode или транслитерацию Velthuis.

## Как работают обновления

Приложение может проверять наличие новых релизов на GitHub.

- Если доступна новая версия приложения, оно может скачать новый APK и открыть установщик Android.
- Android по-прежнему требует подтверждения шага установки. Обновления приложения не происходят полностью автоматически.
- База данных словаря также может обновляться автоматически в фоновом режиме.
- Если приложение настроено на загрузку обновлений только по Wi-Fi, фоновые загрузки будут ждать подключения к Wi-Fi.

В период бета-тестирования обновления могут выходить чаще, чем в стабильном релизе.

Кратко:

- Обновление приложения: автоматическая проверка/загрузка, затем Android просит подтвердить установку.
- Обновление базы данных: автоматическая фоновая загрузка и применение.

## Быстрое устранение неполадок

### Браузер предупреждает, что файл может быть вредоносным

Это стандартное предупреждение, которое появляется для любого APK-файла, скачанного не из Play Store. Это не означает, что файл опасен — это означает, что APK-файлы Android не проверяются системами Google так, как приложения из Play Store.

Исходный код этого приложения полностью открыт и может быть прочитан любым желающим по адресу <https://github.com/digitalpalidictionary/dpd-flutter-app>. Ничего скрытого нет. Нажмите **Сохранить** или **Загрузить всё равно**, чтобы продолжить.

### APK-файл не устанавливается

- Повторно откройте APK после разрешения установки из этого источника.
- При необходимости попробуйте открыть файл снова из списка загрузок браузера или из файлового менеджера.

### Приложение не обновляется сразу

- Убедитесь, что устройство подключено к интернету.
- Проверьте, не ограничены ли обновления только Wi-Fi в настройках приложения.
- Вы также можете использовать кнопку `Обновить сейчас` в настройках приложения.

### Я нашёл ошибку в словаре

- Откройте запись, нажмите кнопку `обратная связь` внизу и выберите `Исправить ошибку`.
