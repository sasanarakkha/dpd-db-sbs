# Информация о сутте

Вкладка «Сутта» содержит подробную информацию о беседе (сутте).

Она решает одну из главных проблем разных наборов палийских текстов, а именно **различия в системах нумерации**. За основу взята нумерация Chaṭṭha Saṅgāyana, а все остальные палийские тексты сопоставляются по соответствующей сутте, а не по номеру (который может различаться).
